# Тренажёр экзамена по приёму кода Морзе

Веб-приложение на Vue 3 + TypeScript для тренировки приёма кода Морзе на слух
(1-я квалификационная категория радиолюбителя).

## Условия теста

- Скорость приёма: 60 знаков в минуту (настраивается).
- Объём текста: 250 знаков.
- Допустимое число ошибок: не более 3.
- Время на выполнение: 15 минут.

## Возможности

- Стартовый экран с настройкой скорости и набора символов:
  - Латиница
  - Латиница + цифры
  - Кириллица
  - Кириллица + цифры
  - Цифры
  - Свой набор символов
- Генерация кода Морзе тоном 1000 Гц, группы по 5 символов.
- Ввод принятых символов с клавиатуры; отображение по 5 символов в группе и
  5 групп в строке.
- Точки на месте ещё не введённых символов, заменяются на введённые.
- Прерывание теста клавишей `Esc`.
- Индикатор прогресса в процентах.
- Экран результатов: число символов и ошибок, цветовой вердикт,
  переданный и принятый текст с подсветкой ошибок.
- Отдельная вкладка «Код Морзе» с таблицами символов и напевов
  (`LATIN`, `CYRILLIC`, `DIGITS`).
- Сохранение выбранного набора символов и своего набора в `localStorage`.

## Критерии оценки

- **зелёный** «Тест пройден без ошибок» — переданы все 250 символов,
  приняты все 250, ошибок нет;
- **жёлтый** «Тест пройден, ошибок: N» — переданы все 250 символов,
  ошибок не более 3;
- **красный** «Тест не пройден, ошибок: N» — передано меньше 250 символов
  или ошибок больше 3.

Принятый текст (с жёлтой подсветкой ошибок) показывается для любого
не-зелёного результата.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу, который выведет Vite (обычно
`http://localhost:5173`).

## Скрипты

- `npm run dev` — запуск dev-сервера.
- `npm run build` — проверка типов и сборка в `dist/`.
- `npm run preview` — предпросмотр собранной версии.
- `npm run typecheck` — проверка типов (`vue-tsc`).

## Структура

```
index.html
src/
  main.ts                 точка входа
  App.vue                 состояние экранов, заголовок вкладки
  types.ts                типы и константы
  style.css               стили
  components/
    SettingsScreen.vue    начальные условия
    TestScreen.vue        прохождение теста
    ResultScreen.vue      результаты
    MorseTables.vue       таблицы символов и напевов
  lib/
    morse.ts              таблицы LATIN / CYRILLIC / DIGITS (код и напев)
    charset.ts            варианты набора символов
    generate.ts           генерация текста
    player.ts             воспроизведение кода Морзе (Web Audio)
    format.ts             группировка текста 5×5
    storage.ts            сохранение настроек в localStorage
    tablesWindow.ts       открытие вкладки с таблицами
```

## Технологии

- Vue 3 (`<script setup>`, TypeScript)
- Vite
- Web Audio API
